# Vodomont BL — sajt (statička verzija)

Spreman za besplatno hostovanje na **GitHub Pages**.

## Sadržaj
- `index.html` — cijela stranica (HTML + CSS u jednom fajlu)
- `images/` — logo i fotografije radova
- `.nojekyll` — da GitHub Pages servira fajlove bez obrade

## Objava na GitHub Pages
1. Napravi novi repozitorij na GitHubu (npr. `vodomont`).
2. Otpremi (upload) SVE iz ovog foldera u repozitorij — `index.html`, folder `images/` i `.nojekyll`.
3. U repozitoriju idi na **Settings → Pages**.
4. Pod **Build and deployment → Source** izaberi **Deploy from a branch**,
   branch: `main`, folder: `/ (root)`, pa **Save**.
5. Za minut-dva sajt će biti dostupan na adresi:
   `https://<tvoj-korisnicki-nalog>.github.io/vodomont/`

## Kasnije (kad kupiš domen)
- Dodaj domen pod **Settings → Pages → Custom domain**.
- Kod registratora domena podesi DNS kako GitHub traži.

## Napomene
- Poziv (tel) i Viber linkovi rade na pravom sajtu (na telefonu otvaraju pozivanje / Viber).
- Dugme/mapa „Pogledajte na mapi" vodi na Google Mape (pretraga lokacije).
- Fotografije radova su u `images/` — zamijeni ih ili dodaj nove po potrebi.
